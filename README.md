# PDF Layout Diff

在本机比较两份 PDF 的页面外观和文字排版。支持独立选页、叠加预览、局部测量，以及可离线查看的比较报告。

## 功能

- **六种视图**：参考页、待比较页、红蓝叠加、差异热图、并排和闪烁。
- **全页比较**：两份 PDF 页数相同时，可按相同页码一次比较全部页面，查看进度、逐页摘要并筛选有差异的页面。
- **高分辨率查看**：96、150、200、300、600 DPI，同步缩放、滚动和拖动。
- **区域比较**：拖拽框选或输入毫米坐标，单独测量页面中的任意区域。
- **差异量化**：墨迹不重合率、RGB 差异、轮廓距离，以及匹配文字的位置、行距、字号和字体名变化。
- **差异诊断**提供文字增删改、局部排版差异、连续行偏移规律和视觉差异区域，并记录定位、调整目标与可靠性依据。
- **结果导出**：JSON 数据、自包含 HTML 报告、PNG 图片和 ZIP 文件。
- **本地处理**：界面不依赖 CDN，PDF 不发送至第三方服务，安装依赖后可以离线使用。

通过本地浏览器界面运行，支持指定单页比较，以及相同页数文档的全部页面比较。

## 安装与启动

需要 Python 3.11 或更新版本和现代浏览器。以下命令在源代码目录执行。

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install .
.\.venv\Scripts\python.exe -m pdfdiff
```

### Linux / macOS

```sh
python3 -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/python -m pdfdiff
```

启动后打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。按 `Ctrl+C` 关闭服务。不需要 Node.js、Poppler 或 ImageMagick 来运行软件。

安装后也可以使用虚拟环境中的 `pdf-layout-diff` 命令；`python run.py` 保留为源码启动方式。上述启动入口均支持 `--port`，例如：

```powershell
.\.venv\Scripts\python.exe -m pdfdiff --port 8766
```

首次安装依赖需要联网，安装完成后可以离线使用。

## 使用

1. 在“参考 PDF”和“待比较 PDF”两侧分别选择或拖入文件。
2. 选择比较范围、设置 DPI，点击“开始比较”。单页模式可独立指定两侧页码；全页模式仅在页数相同时可用，按第 1 页对第 1 页、第 2 页对第 2 页依次处理。
3. 切换视图查看差异；并排模式下两页同步滚动。按住 `Ctrl` 滚动鼠标可围绕指针缩放。
4. 如需局部测量，使用“框选测量”或填写区域坐标，再重新比较。
5. 查看测量值、匹配行和提示信息，导出所需的报告或图片。

点击“试用内置示例”可以直接查看效果。示例第一页具有已知的 1 mm 横移、0.5 mm 初始纵移和 0.12 mm 正文行距变化；第二页包含字号、字体、内容和边框变化。

文件、页码、区域或参数改变后，已有结果会标记为过期，重新比较前不能导出为当前设置的结果。

### 全页比较

全页模式显示已处理页数、进度和每页结果，可筛选有视觉差异的页面，并点击页面查看原有六种视图和详细测量。页面详情切换不会重新提交整份比较。全页比较不应用局部选区；需要框选时切换到单页模式。

页面会逐个处理，完整图像仅在查看详情时按需渲染。可取消当前任务；取消会在正在处理的页面结束后生效，保留已完成的摘要。页面处理错误会单独列出，未完成和错误页面不会计为无差异。

全页模式的 JSON、HTML、ZIP 导出包含整份比较摘要和各页差异诊断。ZIP 包含逐页测量 JSON，页面图片可从对应页的详情单独导出。摘要中的“有 / 无视觉差异”依据渲染像素和页面几何信息判定，不等同于文件内部结构或全部文字内容相同。

### 差异诊断

比较完成后，在“差异诊断”中展开条目，查看参考与待比较内容的位置、文字片段、测量值、调整目标及可靠性证据。页面详情提供同一物理区域的参考图、待比较图和差异图，便于核对局部变化。完整诊断保存在 JSON 的 `diagnostics` 字段，单页和全页导出均会保留。

| 字段 | 内容 |
| --- | --- |
| `conventions` / `tolerances` | 坐标、单位、差值方向及诊断容差 |
| `summary` / `coverage` | 诊断数量、类型与测量覆盖情况 |
| `findings[].reference` / `candidate` | 两侧页码、文字锚点、上下文和定位框 |
| `findings[].measurements` | 参考值、待比较值、差值、单位与统计方法 |
| `findings[].target` | 输出层面的调整目标，可靠平移可提供反向调整量 |
| `findings[].reliability` | 对应可靠程度、理由和支持该判断的测量证据 |
| `findings[].source_location` | 源码位置，当前为 `null`，供后续结合源工程定位 |
| `limitations` / `truncated` | 无法诊断的情况，以及是否达到数量限制 |

连续行的诊断描述经过检验的行组与偏移趋势。文字内容、字体或换行变化时，应先核对对应关系，再使用位置数值。视觉区域表示渲染差异的范围，具体对象类型需要结合图像判断。

调整目标描述需要达到的 PDF 输出效果。修改源文件时需要结合工程中的正文和样式定义，重新生成 PDF 后再次比较，核对差异是否缩小。诊断容差与原始像素差异分别记录，可用于检查小幅残余变化。

位置与行距诊断默认采用 0.05 mm 容差，字号采用 0.05 PDF pt。每页最多保留 1000 条诊断、64 个视觉区域，离线单页 HTML 最多展示 12 个视觉区域的局部图。达到上限时，`truncated` 与 `coverage` 会记录省略情况。视觉区域仍按全部 RGB 变化像素定位和计数。

## 测量说明

所有位置差与字号差均为 **待比较值减参考值**。横向正值表示向右，纵向正值表示向下。

| 指标 | 含义 |
| --- | --- |
| 墨迹不重合率 | 二值前景异或面积除以双方前景并集面积，越小表示墨迹重合越多 |
| 横向 / 纵向中位偏移 | 匹配字符位置差的中位数，单位 mm |
| P95 位置误差 | 匹配字符二维位移长度的第 95 百分位，单位 mm |
| 行距中位差 | 符合条件的相邻匹配行的基线间距差，单位 mm |
| 字号中位差 | 匹配字符提取字号之差，单位 PDF pt |
| 对称轮廓距离 | 双方前景轮廓到另一侧最近轮廓的平均 / P95 距离 |
| RGB 平均绝对差 / 变化像素数 | 原始颜色差异，可显示墨迹阈值可能忽略的变化 |

`不可测` 或 JSON 中的 `null` 表示缺少可靠数据，不能解释为零误差。图像指标不是整体一致程度的百分比，字体名称相同也不能证明字体文件完全相同。

### 坐标与区域

- 以旋转后可见页（CropBox）的左上角为原点，单位为 mm。
- 不自动配准内容、裁白边或拉伸页面；页面尺寸不同时放入共同白色画布，保留原始物理尺度。
- 文字按字符边界框中心决定是否纳入选区；图像选区左上角向下取整到像素，右下角向上取整，实际范围见 JSON 的 `settings.effective_region_px`。
- 区域只影响测量范围，图片保留整页。离线 HTML 使用虚线标出选区；PNG 不附加区域标记。

### 限制

- 不执行 OCR。扫描件或文字转曲的 PDF 可以比较图像，通常无法测量文字位置、字体和行距。需要密码的 PDF 暂不支持。
- 文字按提取顺序匹配。重复文本、复杂分栏、连字、公式、内容增删和换行变化可能影响匹配，需结合原图和未匹配字符数复核。
- 测量区域超过 8000 个非空白字符时跳过文字位置、字号和行距匹配。具体文字增删改独立支持最多 12000 个含空格字符，超过该值时跳过内容比对。覆盖范围和跳过原因记录在报告中。共同文字不足时不计算位置。
- 页面内容的位置不能直接还原源文档的段落设置。文字边界框高度不等于字号或真实墨迹高度。
- 600 DPI 的采样间距约为 0.0423 mm，采样间距与坐标显示的小数位均不代表实际测量准确度。对不同版本进行回归比较时应固定 DPI、阈值和字体环境。
- 公共画布最多 4000 万像素，单边不超过 10000 像素；较大页面需要降低 DPI。

## 数据与隐私

程序默认只监听 `127.0.0.1`，面向单人本地使用。上传的 PDF 和比较结果保存在服务进程内存中，不作为应用文件持久化；闲置 60 分钟后过期，每分钟执行清理。停止服务会清空缓存，重启或刷新页面后可能需要重新选择文件。

文档缓存最多保留 12 份文档（单份 32 MiB、合计 128 MiB）；单页结果和全页任务各最多保留 4 份，达到容量限制时淘汰最久未使用的已结束记录。一次只能运行一个全页任务，运行中的任务不会被过期清理或容量淘汰。

全页任务另保留源文件引用，以便在文档缓存被淘汰后仍能查看该任务的页面详情。每份全页摘要最多 64 MiB，达到上限时停止任务并保留已完成的结果；整份高分辨率页面图片不会常驻缓存。

报告包含文件名、SHA-256、测量参数、软件版本、文字片段和页面图片；ZIP 不包含原始 PDF。导出文件由用户保存，分享前应检查其中的敏感信息。

## 开发与构建

在虚拟环境中安装开发依赖：

```sh
python -m pip install -e '.[dev]'
python -m pytest
python -m build
```

以上 `python` 指虚拟环境中的解释器。构建产物位于 `dist/`，包括 wheel 和源码分发包。修改前端 JavaScript 时另执行 `node --check pdfdiff/static/app.js`；Node.js 仅用于开发检查。
